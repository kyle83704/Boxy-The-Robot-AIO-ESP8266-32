Arduino Song Converter for Boxy

This tool helps you convert an Arduino song sketch into a format that works with your robot's song.h file.

  1. Find a song online (e.g., https://github.com/robsoncouto/arduino-songs/ ).
  2. Copy the entire code, including the #define notes, melody[] array, and tempo variable.
  3. Paste the code into the text area below.
  4. Click "Convert Song".
  5. Copy the generated code and paste it into your song.h file.

Example of what to paste:

#define NOTE_B0  31
#define NOTE_C1  33
// ... all the other notes ...
#define REST     0

int tempo = 85;

int melody[] = {
  // Jigglypuff's Song
  NOTE_D5,-4, NOTE_A5,8, NOTE_FS5,8, NOTE_D5,8,
  // ... rest of the melody ...
};
