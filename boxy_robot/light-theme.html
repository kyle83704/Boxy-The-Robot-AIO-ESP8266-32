Joystick Control

Instructions:

  • Use the joystick to control robot movement.
  • Adjust Max Speed to set the robot's top speed.
  • Control the servo angle.
  • Toggle the onboard LED and trigger the buzzer.
  • Hold the Horn button to make a sound at the selected frequency.

Dual Joystick Control

Left Motor

Right Motor

Instructions:

  • Use the left joystick to control the left motor's speed and the right joystick for the right motor's speed.
  • Adjust Max Speed to set the robot's top speed.
  • Control the servo angle.
  • Hold the Horn button to make a sound at the selected frequency.
  • This mode provides independent control over each motor for precision.

Roam Mode

Instructions:

  • Place the robot on a black line on a white surface, or a white line on a black surface (depending on sensor setup).
  • Click "Start Roam" to begin autonomous Roaming.
  • Click "Stop Roam" to halt the robot.

ByLine Mode

Instructions:

  • Use the predefined buttons to send common commands.
  • "Set Speed" allows you to set the max speed (0-255) for ByLine mode.
  • "Set Servo" allows you to set the servo angle (0-180).
  • Use the "Custom Command" input for direct commands like "f,1000" (forward for 1000ms), "b,500" (backward for 500ms), "l,300" (left for 300ms), "r,300" (right for 300ms), "p,700" (set PWM/speed to 700), "s,90" (set servo to 90 degrees).
